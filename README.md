# 365HopeJourney ✨

Plataforma completa de desenvolvimento espiritual, e-books, meditações guiadas, reflexões diárias e mentoria com inteligência artificial.

## 🚀 Tecnologias
- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons
- **Backend / DB**: Firebase Cloud Firestore, Supabase
- **IA**: Anthropic Claude & Google Gemini
- **Mobile**: Capacitor (iOS & Android)

## 📦 Como rodar localmente
```bash
npm install
npm run dev
```

## 🌐 Deploy
Implantado via Vercel e Firebase.
